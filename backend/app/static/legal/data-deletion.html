ChildSafe provides this page so people can request deletion of personal information associated with their use of the website, a report, or an authorized integration.

How to request deletion

  1. Email suelmaparis@hotmail.com with the subject “ChildSafe data deletion request”.
  2. Explain which information you want deleted. If available, include the report ID or the email address you used when contacting ChildSafe.
  3. Provide only enough information to help locate the record. Do not attach images or videos of children, identity documents, passwords, or other sensitive information unless ChildSafe specifically explains a secure and necessary method.
  4. We may contact you to clarify the request or reasonably verify that you are entitled to request deletion.

Send a deletion request by email

What happens next

ChildSafe will review the request and take reasonable steps to delete or de-identify the relevant information where appropriate. Some records may be retained when necessary for child-safety investigations, preventing abuse, security, audit integrity, resolving disputes, or complying with legal obligations. If information must be retained, it will be limited to what is reasonably necessary and protected accordingly.

We do not provide an automatic deletion callback through this page. This page is a set of instructions for submitting a request by email. Do not use it to report an immediate emergency; contact local emergency services if a child or another person is in immediate danger.

Contact

Data deletion requests: suelmaparis@hotmail.com.

Instruções para Eliminação de Dados (Português)

Podes pedir a eliminação de dados pessoais relacionados com o uso do site ChildSafe, uma denúncia ou uma integração autorizada.

  1. Envia um email para suelmaparis@hotmail.com com o assunto “Pedido de eliminação de dados ChildSafe”.
  2. Explica quais os dados que pretendes eliminar. Se tiveres, inclui o identificador da denúncia ou o email usado para contactar o ChildSafe.
  3. Inclui apenas os dados necessários para localizar o registo. Não anexes imagens ou vídeos de crianças, documentos de identidade, palavras-passe ou outros dados sensíveis.
  4. Poderemos pedir esclarecimentos ou uma verificação razoável para confirmar que podes fazer o pedido.

O pedido será analisado e serão tomadas medidas razoáveis para eliminar ou desidentificar os dados quando apropriado. Alguns registos poderão ser conservados quando necessário para a segurança infantil, prevenção de abusos, segurança informática, auditoria ou cumprimento da lei. Esta página recebe pedidos por email; não é um mecanismo automático de eliminação. Em caso de perigo imediato, contacta os serviços de emergência locais.
